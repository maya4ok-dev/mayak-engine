# mayak-engine

an experimental c++ game engine library with lua integration

## highlights

- entity-component system
- lua integration
- sdl3-based renderer
- cmake build system

## getting started

### requirements

- c++20 compiler
- cmake
- sdl3

---

1. clone the repo with submodules
2. build the project using cmake
3. run an example while being in the game/ directory
