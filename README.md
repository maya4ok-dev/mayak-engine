# mayak-engine

an experimental, learning 2D game engine written in C++ using SDL3 and Lua.

## history

I was late 13/early 14 when I started learning C++ and I was curious to make a game engine.
that's how this game engine appeared.

this was my first C++ project. Yes, I started learning C++ with CMake, SDL3, C++ Lua wrapper, and then even Doxygen.
