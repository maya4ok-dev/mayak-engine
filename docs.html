1. CHANGING MAIN.CPP

By default, main.cpp contains headers and main function, which is the entry point of the program.

First of all, you should create a dimension. Here is an example:

#include "engine/Object.h" #include "engine/DIM.h" #include "engine/Renderer.h" int main() { DIM startDim(20, 20); return 0; }

Here, we created a dimension with 20x20 size. You can change it to any size you want.

Then, you can create an object. It takes 6 arguments:

  • posX - x coordinate of the object
  • posY - y coordinate of the object
  • height - height of the object
  • width - width of the object
  • dim - dimension of the object
  • type - type of the object (usually uses for scripts)

Here is an example:

#include "engine/Object.h" #include "engine/DIM.h" #include "engine/Renderer.h" int main() { std::vector<Object> objects; DIM dim(20, 20); objects.emplace_back(0, 0, 1, 1, dim, "player"); return 0; }

2. COMPILING PROJECT

This engine uses CMake to compile project.

First of all, you should download a C/C++ Extension Pack, which has CMake tools.

Then press run button on status bar and wait until it's completed.

After building, your project will run automatically

Also you can run it by just running executable file in the build folder.

If not, read the output, your project may contain some errors.
